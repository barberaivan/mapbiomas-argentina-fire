veg_fire_remap.csv — metadata
==============================

WHAT
  Canonical, language-agnostic remap table from MapBiomas Argentina land-cover
  classes (country-level, level-2/3) to the project's veg_fire classes, per region.
  Single source of truth for the reclassification, loaded by both Python
  (utils/constants.py) and R (model fitting). This CSV — not the Google Sheet — is
  what the code reads.

DO NOT EDIT BY HAND
  Edit the Google Sheet, then regenerate. Hand edits will be overwritten.

SOURCE
  Google Sheet (human-facing source / editing surface), tab = "remap_by_region":
  https://docs.google.com/spreadsheets/d/17ZShb8D0JaJw4nLvBDzt19xF6Fdg8lGHYs4Jogh0X1A/edit?gid=1376068841

GENERATED BY
  collection-01/scripts/veg-fire_remap_clean-google-sheet.R
  Regenerate (from repo root):
    Rscript collection-01/scripts/veg-fire_remap_clean-google-sheet.R

COLUMNS
  mb_class_raw   int   MapBiomas country-level land-cover class id (level 2/3).
                       Same name as the band/column in the training data, so it
                       joins directly.
  arg_name       str   MapBiomas country-level class name (Argentina legend).
  region         str   Region name (BA, CHACO, PAMPA, CUYO, PAT).
  region_num     int   Region code, matching the GEE region-id raster.
  local_class    str   Region-wise name(s) for the class; may list several.
  veg_fire       int   veg_fire class code, 1..K. Fittable classes first, then
                       the non-fittable ones.
  veg_fire_name  str   Post-workshop physiognomic class name. Region(s) embedded
                       in the name so codes don't repeat across regions.
  fittable       bool  TRUE for classes that get a model; FALSE for non-burnable
                       and non-observed.

KEYS / USAGE
  Join key is (region_num, mb_class_raw): the same MB class maps to different
  veg_fire classes depending on region.
  - Model fitting (R): join training observations on (region, mb_class_raw),
    drop rows where fittable == FALSE.
  - Prediction (GEE/Python): remap (region_num, mb_class_raw) -> veg_fire; pixels
    of non-fittable classes get no model and are flagged in QA bands.

CONVENTIONS
  - Rows with id = NA in the sheet (level-1 grouping rows) are dropped.
  - "No Observado" is level 1 but has id = 27, so rows are filtered on id, not level.
  - Rows with an empty veg_fire_name are dropped: an MB class with no veg_fire name
    means that class does not occur in that region, so it gets no row (keeping it
    would invent a veg_fire class with no data). The script logs every dropped row.
  - Non-fittable classes ("non-burnable", "non-observed") are kept and numbered so
    they remain identifiable for QA and training filtering.
